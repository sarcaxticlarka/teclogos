## 1. Project Overview

This repository houses the modern, premium, enterprise-grade digital platform for **TecLogos Automation Private Limited**.  the platform elevates TecLogos from a local panel/integration firm into an authoritative, vendor-independent systems integration and detailed engineering consultancy partner.

### Key Architectural Pillars
* **Vendor-Independent Multi-OEM Integration:** Deep engineering documentation across Honeywell (Experion PKS, TPS, C300/C200, FSC, Safety Manager), Siemens (SIMATIC S7-1500/1200, TIA Portal, WinCC Unified), ABB (System 800xA, Freelance AC 800M/800F), Rockwell Automation (Allen-Bradley Logix), and Tridium Niagara (Niagara N4 Open BMS).
* **Deep Deliverable Catalogs:** Page-by-page technical breakdowns detailing standards (IEC 61131-3, IEC 61508/61511, ISA-88/95/101/18.2, IEEE), I/O specifications, cable schedules, and FAT procedures.
* **Interactive Engineering RFQ Builder:** Multi-step wizard allowing EPC contractors and plant directors to scope projects by industry, control architecture, I/O count, and project phase with direct routing to Pune technical leadership.
* **Interactive Automation Hierarchy Explorer:** Dynamic 4-level industrial pyramid visualization (Level 0 Field I/O $\rightarrow$ Level 1 Real-Time Controllers $\rightarrow$ Level 2 SCADA/HMI $\rightarrow$ Level 3 Historian & Operations) explaining complex control concepts in simple terms.
* **Zero External Dependencies:** Handcrafted SVG iconography and modular typography ensuring 100% build reliability, zero version conflicts, zero font layout shifts (CLS = 0), and lightning-fast sub-second static page generation.

## 3. Technology Stack & Framework Choices

* **Framework:** Next.js 16.4.5 (App Router with full static pre-rendering)
* **Runtime:** React 19.3.0
* **Styling:** Tailwind CSS v4 with bespoke industrial design tokens, technical grid lines, and responsive layouts
* **Language:** TypeScript 5.x with strict type safety across all data structures
* **Bundler:** Webpack-optimized Next.js production compiler
* **Typography:** Modern high-performance industrial system font stack (`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial`) ensuring zero network font fetch failures during sandboxed offline builds.

## 4. Local Development & Build Instructions

### Prerequisites
* Node.js v20+ or v24+
* npm, pnpm, or yarn

### Installation & Execution
```bash
# Clone the repository
cd tech-logos

# Start local development server
npm run dev
# Opens at http://localhost:3000

# Build optimized production bundle
npm run build

# Start production server
npm run start
```
